# 第零章 预备知识

## 0.1 集合与映射

设 A、B 是两个非空集合。所谓从 A 到 B 的一个**映射** f，是指一个对应法则，它使得 A 中每个元素 a 都有 B 中唯一确定的元素 f(a) 与之对应。记作 f: A → B。

若 f(a) = f(b) 当且仅当 a = b，则称 f 是**单射**；若对每个 b ∈ B 都存在 a ∈ A 使 f(a) = b，则称 f 是**满射**。既是单射又是满射的映射称为**双射**（一一对应）。

## 0.2 等价关系与分类

设 S 是一个非空集合，~ 是 S 上元素间的一个关系。如果 ~ 满足：

1. **自反性**：对任意 a ∈ S，有 a ~ a；
2. **对称性**：若 a ~ b，则 b ~ a；
3. **传递性**：若 a ~ b 且 b ~ c，则 a ~ c，

则称 ~ 是 S 上的一个**等价关系**。

等价关系把 S 分成若干互不相交的**等价类**的并：每个元素恰好属于一个等价类。这一事实称为集合的一个**分类**。

## 0.3 整数的整除与带余除法

对整数 a, b（b ≠ 0），若存在整数 q 使 a = qb，则称 b 整除 a，记作 b | a。

对任意整数 a 和正整数 n，存在唯一的一对整数 q 和 r，使

  a = qn + r，其中 0 ≤ r < n。

这称为**带余除法**。特别地，两个整数 a, b 除以 n 的余数相同（即 n | a − b）时，记 a ≡ b (mod n)，称为**模 n 同余**。模 n 同余是整数集上的一个等价关系。

# 第一章 群的定义与基本性质

## 1.1 二元运算

**定义 1.1.1（二元运算）** 设 S 是一个非空集合。如果映射

  μ : S × S → S

即对 S 中任意两个有序元素 (a, b)，都有 S 中唯一确定的元素 μ(a, b) 与之对应，则称 μ 是 S 上的一个**二元运算**，简记为 ab（乘法记法）或 a + b（加法记法）。

换言之，二元运算就是"集合中任意两个元素结合之后仍在集合中"的法则，这一性质称为**运算的封闭性**。

**例 1.1.2** 下列运算是二元运算：

1. 整数集 ℤ 上的普通加法：任意两个整数之和仍是整数；
2. 正有理数集 ℚ⁺ 上的普通乘法；
3. 集合 X 上的全体映射构成的集合 Map(X, X) 关于映射的复合。

**例 1.1.3** 下列运算**不是**二元运算：

1. 自然数集 ℕ 上的减法：1 − 2 = −1 不属于 ℕ（不封闭）；
2. ℤ 上的除法：1 ÷ 2 ∉ ℤ（不封闭）。

**定义 1.1.4（结合律与交换律）** 设 ∘ 是集合 S 上的二元运算。

1. 若对任意 a, b, c ∈ S 都有 (a ∘ b) ∘ c = a ∘ (b ∘ c)，则称 ∘ 满足**结合律**；
2. 若对任意 a, b ∈ S 都有 a ∘ b = b ∘ a，则称 ∘ 满足**交换律**。

**注 1.1.5** 当运算满足结合律时，a₁a₂⋯aₙ 不加括号有意义。但**交换律不能推出结合律**，结合律也不能推出交换律：两者互相独立。

**例 1.1.6** 设 a, b 是实数，定义运算 a ∘ b = a + b + ab。这个运算满足交换律（显然 a+b+ab = b+a+ba），也可以验证它满足结合律。

## 1.2 群的定义

**定义 1.2.1（群）** 设 G 是一个非空集合，∘ 是 G 上的一个二元运算。如果下列四个条件（**群公理**）都成立，则称 (G, ∘) 是一个**群**：

1. **封闭性**：对任意 a, b ∈ G，a ∘ b ∈ G；
2. **结合律**：对任意 a, b, c ∈ G，(a ∘ b) ∘ c = a ∘ (b ∘ c)；
3. **单位元存在**：存在元素 e ∈ G，使得对任意 a ∈ G，e ∘ a = a ∘ e = a；
4. **逆元存在**：对任意 a ∈ G，存在元素 b ∈ G，使 a ∘ b = b ∘ a = e。

若还满足**交换律**（对任意 a, b ∈ G，a ∘ b = b ∘ a），则称 G 是一个**交换群**（Abel 群）。

满足条件 1、2、3 而不满足条件 4 的代数结构称为**幺半群**。

**例 1.2.2** ℤ 关于普通加法构成交换群：封闭性与结合律是熟知的；0 是单位元；每个整数 a 的逆元是它的相反数 −a。ℤ 关于普通乘法**不是**群：虽然 1 是单位元，但 2 的逆元 1/2 ∉ ℤ（逆元不存在）。

**例 1.2.3** 正有理数集 ℚ⁺ 关于乘法构成交换群：单位元是 1，每个 q ∈ ℚ⁺ 的逆元是 1/q。

**例 1.2.4（模 n 剩余类加法群）** 把整数按模 n 同余分类，得到 n 个剩余类 [0], [1], …, [n−1]（参见第零章 0.2 与 0.3）。定义 [a] + [b] = [a + b]。由带余除法可以验证这个定义与代表元的选取无关，因而它是 ℤₙ = {[0], [1], …, [n−1]} 上的二元运算。(ℤₙ, +) 构成交换群：单位元是 [0]，[a] 的逆元是 [−a] = [n − a]。

**例 1.2.5（Klein 四元群）** 设 G = {e, a, b, c}，运算由下表给出：

|  ∘ | e | a | b | c |
|----|---|---|---|---|
| e  | e | a | b | c |
| a  | a | e | c | b |
| b  | b | c | e | a |
| c  | c | b | a | e |

可以验证它构成交换群，其中每个非单位元都以自身为逆元：a∘a = e，b∘b = e，c∘c = e。

**注 1.2.6（判断一个结构是不是群的标准程序）** 按顺序检查四件事：是否封闭 → 是否满足结合律 → 找单位元 → 验证每个元素有逆元。任何一步失败就立刻排除。判断"不是群"最常见的办法是：找一个具体元素，说明它的逆元不在集合中（如例 1.2.2 中的 ℤ 对乘法），或说明运算不封闭（如 ℕ 对减法）。

## 1.3 群的基本性质

**定理 1.3.1（单位元的唯一性）** 群 G 的单位元是唯一的。

**证明** 设 e 与 e′ 都是 G 的单位元。把 e 看作单位元，则有 e′ = e ∘ e′（e 是单位元）；把 e′ 看作单位元，又有 e ∘ e′ = e。于是 e′ = e ∘ e′ = e。∎

**定理 1.3.2（逆元的唯一性）** 群 G 中每个元素 a 的逆元是唯一的，记作 a⁻¹。

**证明** 设 b 与 c 都是 a 的逆元，即 a∘b = b∘a = e 且 a∘c = c∘a = e。则

  b = b ∘ e = b ∘ (a ∘ c) = (b ∘ a) ∘ c = e ∘ c = c，

第一步与最后一步用单位元性质，中间用结合律。所以 b = c。∎

**定理 1.3.3（消去律）** 在群 G 中，若 a ∘ b = a ∘ c 或 b ∘ a = c ∘ a，则 b = c。

**证明** 用 a⁻¹ 从左侧乘 a∘b = a∘c 两端：

  a⁻¹ ∘ (a ∘ b) = (a⁻¹ ∘ a) ∘ b = e ∘ b = b，

同理右端为 c，故 b = c。右侧情形同理。∎

**定理 1.3.4（方程的可解性）** 在群 G 中，方程 a ∘ x = b 与 y ∘ a = b 都有唯一解：x = a⁻¹ ∘ b，y = b ∘ a⁻¹。

**证明** 代入验证：a ∘ (a⁻¹ ∘ b) = (a ∘ a⁻¹) ∘ b = e ∘ b = b，故 x = a⁻¹∘b 是解；由消去律（定理 1.3.3）知解唯一。另一方程同理。∎

**注 1.3.5** 在交换群中 a⁻¹ ∘ b = b ∘ a⁻¹，两个方程同解；在非交换群中两者一般不同，顺序不可随意交换。

**性质 1.3.6（逆元的性质）** 在群 G 中：

1. (a⁻¹)⁻¹ = a；
2. (a ∘ b)⁻¹ = b⁻¹ ∘ a⁻¹（**穿脱原理**：先穿袜子后穿鞋，脱的时候顺序相反）。

**证明** 第 1 条：a⁻¹ 的逆元满足 a⁻¹ ∘ x = e，显然 x = a 满足，由逆元唯一性即得。

第 2 条：验证 (a∘b) ∘ (b⁻¹∘a⁻¹) = a ∘ (b ∘ b⁻¹) ∘ a⁻¹ = a ∘ e ∘ a⁻¹ = e，由结合律逐层消去；同理 (b⁻¹∘a⁻¹) ∘ (a∘b) = e。故 b⁻¹∘a⁻¹ 是 a∘b 的逆元。∎

**注 1.3.7** 穿脱原理在非交换群中尤其重要：一般 (a∘b)⁻¹ ≠ a⁻¹ ∘ b⁻¹。例如例 1.2.5 的 Klein 四元群中取 a, b：(a∘b)⁻¹ = c⁻¹ = c，而 a⁻¹∘b⁻¹ = a∘b = c，此处恰好相等是因为该群是交换群；对非交换的结构则不一定成立。

## 1.4 简单应用与例题

**例 1.4.1** 验证例 1.2.4 中 (ℤ₃, +)（n = 3）构成群，并求 [2] 的逆元。

**解** ℤ₃ = {[0], [1], [2]}。封闭性：加法表每项仍是剩余类。结合律：([a]+[b])+[c] = [a+b+c] = [a]+([b]+[c])。单位元：[0]。逆元：[0]⁻¹ = [0]，[1]⁻¹ = [2]（因为 [1] + [2] = [3] = [0]），[2]⁻¹ = [1]。四个条件都满足，故 (ℤ₃, +) 是群，且是交换群。[2] 的逆元是 [1]。

**例 1.4.2** 在群 G 中，已知 a ∘ b ∘ c = e，求 c（用 a、b 的逆元表示），并进一步求 c⁻¹。

**解** 先求 c。由 a∘b∘c = e 得 (a∘b)∘c = e，即 c 是 a∘b 的右逆；群中右逆必是逆元（由逆元唯一性与 a∘(a⁻¹)=e 对称地成立），故

  c = (a∘b)⁻¹ = b⁻¹ ∘ a⁻¹（穿脱原理）。

再求 c⁻¹。由性质 1.3.6(1)（(x⁻¹)⁻¹ = x）立得

  c⁻¹ = ((a∘b)⁻¹)⁻¹ = a ∘ b。

验证：一方面 a∘b∘c = e 是已知；另一方面 c∘(a∘b) = (b⁻¹∘a⁻¹)∘(a∘b) = b⁻¹∘(a⁻¹∘a)∘b = b⁻¹∘e∘b = e（利用结合律把中间两个先结合）。可见 a∘b 与 c 互为逆元。

**注意**：c = b⁻¹∘a⁻¹ 与 c⁻¹ = a∘b 是两回事——前者是"c 的表达式"，后者是"c 的逆元的表达式"，不要混淆。

**例 1.4.3（反例：幺半群不是群）** ℕ ∪ {0} 关于加法：封闭、结合，0 是单位元，但除 0 外任何元素没有逆元。它是幺半群而非群。

## 1.5 本章小结

1. 二元运算的核心是**封闭性**；结合律保证运算可去括号；交换律与结合律互相独立。
2. 群 = 封闭 + 结合律 + 单位元 + 每个元素有逆元；四条公理缺一不可。
3. 群的三个基础定理：单位元唯一、逆元唯一、消去律成立——证明都只用了公理本身。
4. 验证"是群"要逐条验证四公理；否定"是群"只需找一个破坏公理的具体反例。
